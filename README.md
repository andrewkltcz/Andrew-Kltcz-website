# Timeline Odyssey

Build a responsive, modern dual-timeline portfolio interactive web page.

### DESIGN & AESTHETICS (BRAND ALIGNED)

- Color Scheme:

  - Base Background: Deep Slate Charcoal (#2B2B2B) or Clean White (#FFFFFF) depending on mode toggle.

  - Accent Color: Electric Cyber Yellow (#FCD12A) for active states, timeline dots, hover highlights, and CTAs.

  - Text & Accents: High-contrast Dark Charcoal (#2B2B2B) and Bright White (#FFFFFF).

- Typography:

  - Header Logo: "ENDRE KULUTACZ" in bold, condensed All-Caps sans-serif (e.g., Oswald/Montserrat).

  - Tagline Sub-Header: "PROJECT MANAGEMENT | CREATIVITY | TECHNOLOGY" in widely-tracked All-Caps.

- Geometric Accents: Use sharp triangular visual cues, angular borders, and the attached logo mark for the top navigation bar.

### LAYOUT STRUCTURE

1. Top / Common Trunk (1990 - 2010):

   - Single centered vertical line starting at 1990 (Birth).

   - Milestones: 1990 (Birth), 2005 (Primary School), 2010 (High School).

   - 2010 - 2013: University (Multimedia Studies) serves as the "Branch Point".

2. Parallel Dual Columns (2013 - Present):

   - Left Column: Professional Track (Technical Writing, Project Management, AI PM).

   - Right Column: Creative Track (Bands, Solo Albums, Videography, 3D Art).

   - Both columns run parallel side-by-side on desktop, sharing the same chronological vertical axis.

3. Mid-Point Convergence Node (2017):

   - A glowing full-width convergence card or bridge at May - Nov 2017 marking "Relocation to Wales, UK" (pausing Aleido & Silent Homes).

   - Draw a clear visual connector line showing the path returning to Aleido in late 2017 to resume growth.

### INTERACTIVITY & HOVER TOOLTIPS

- Each node on the timeline should display: Year, Icon, Role/Project Title.

- Hover / Click Behavior: Hovering or clicking a node smoothly reveals a popover tooltip/card with:

  - Concise description of key achievements or responsibilities.

  - Interactive skill badges / tags (e.g., #ProjectManagement, #TechnicalWriting, #Metalcore, #Blender3D, #VideoProduction).

  - External link placeholder buttons (e.g., "Listen on Spotify", "View Video", "Read Docs").
